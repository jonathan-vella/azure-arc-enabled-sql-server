# Template files and security

Version: v1.2026.09
Last updated: 2026-09-30

Lab scripts write files that contain secrets. The repository ignores those files and commits `.example.json` templates
that show the structure with placeholder values.

## Protected files

All files are under `arc-sql-hands-on-lab/`.

| Ignored file | Committed template | Generated by | Contains |
| --- | --- | --- | --- |
| `bicep/deployment-outputs.json` | `bicep/deployment-outputs.example.json` | `deploy.ps1` | Workspace ID, key, resource names |
| `scripts/service-principal-credentials.json` | `scripts/service-principal-credentials.example.json` | `Create-ArcServicePrincipal.ps1` | Service principal ID and secret |
| `scripts/connectivity-report-*.json` | `scripts/connectivity-report.example.json` | `Test-ArcConnectivity.ps1` | Network test results |

The `.gitignore` entries are `service-principal-credentials.json`, `deployment-outputs.json`, and
`connectivity-report-*.json`, each followed by a `!*.example.json` exception.

## Rules

- Never commit a file that contains real credentials or customer data.
- Store real secrets in Azure Key Vault or a password manager, then delete the generated JSON file.
- Keep the `.example.json` suffix on templates and use placeholder values such as `00000000-0000-0000-0000-000000000000`.
- Do not edit `.gitignore` to allow credential files.

Check that a generated file is ignored before you commit:

```powershell
git check-ignore arc-sql-hands-on-lab/bicep/deployment-outputs.json
```

The command prints the path when the file is ignored.

## Adding a template for a new script

1. Create `<name>.example.json` with placeholder values and a `Note` field that says it is an example.
2. Add the real file name to `.gitignore` and a `!<name>.example.json` exception.
3. Add a row to the table above.

## If a secret was committed

1. Rotate the exposed credential first.
2. Remove it from history with `git filter-repo` or BFG Repo-Cleaner, then force push with the team's agreement.
3. Confirm that no branch or tag still contains it.
